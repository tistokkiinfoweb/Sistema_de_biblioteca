## Tema Escolhido
Sistema de cadastro e procura de livros no acervo literário digital.
<br>

## Integrante

## Descrição
O Sistema possui autores e livros.
<br>

## Entidades do Sistema
1. **Autor**: Quem tem a autoria do livro publicado.
2. **Livro**: Obra cadastrada no acervo.
3. **Usuário**: Quem utiliza o site para cadastrar ou encontrar obras.
